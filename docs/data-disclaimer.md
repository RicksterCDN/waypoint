# Synthetic data disclaimer

Caldova is a fictional company created for this reference application. The suppliers, invoices, contracts, policies, scenarios, findings, evidence, users, and operational records in this repository are synthetic demo data.

The data is designed to feel realistic enough to teach invoice assurance workflows, but it does not represent real companies, contracts, invoices, regulated records, patients, products, or financial obligations.

Do not treat the sample data, policies, or generated recommendations as legal, financial, regulatory, or procurement guidance.
