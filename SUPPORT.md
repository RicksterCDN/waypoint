# Support

Waypoint is a reference application and demo codebase. It is provided as an educational sample for the Caldova scenario, not as a supported Microsoft product.

For questions about adapting the pattern, start with:

- `README.md`
- `docs/status.md`
- `docs/architecture.md`
- `docs/getting-started.md`

Cloud deployment, live Microsoft 365/Fabric/Foundry integration, and tenant-specific configuration may require additional environment setup that is outside the scope of this reference repository.
