# API Supply Agreement: Meridian API Works

**Supplier ID:** sup-004
**Supplier:** Meridian API Works
**Document Type:** API supply agreement and pricing schedule
**Effective Period:** 2026-07-01 through 2027-06-30
**Materials:** AUR-API-7 active pharmaceutical ingredient

## 1. Scope

Meridian API Works will manufacture, test, and release active pharmaceutical ingredient lots for sponsor-approved downstream manufacturing.

## 2. Lot pricing

The contract price is USD 184.00 per gram for released AUR-API-7 lot quantity. Quantity is measured by released lot yield recorded on the certificate of analysis and sponsor receipt.

## 3. Yield true-up

Quarterly yield true-ups must use actual released lot yield, not forecast yield. If actual released yield is lower than forecast, Meridian may not invoice the sponsor for unreleased or failed yield unless a sponsor-approved campaign reservation clause applies.

## 4. Raw material pass-through

Raw material pass-through charges are billable at actual consumed quantity multiplied by approved unit cost. Annual escalation is capped at 4% unless a written procurement approval identifies the material, supplier, and effective date.

## 5. Expedited release

An expedited release fee of USD 12,000 is billable only when the sponsor requests expedited release in writing and the certificate of analysis is delivered at least five business days earlier than the standard release timeline.

## 6. Required invoice support

Invoices must include API lot ID, released grams, certificate of analysis reference, material consumption detail, applicable escalation approval, and expedited release approval when relevant.
