# Workaround for upstream packaging bug (May 2026):
# `agent-framework-core[all]>=1.3.0` transitively requires
# `agent-framework-durabletask`, which depends on a non-existent
# `durabletask` package on PyPI (the published one is
# `durabletask-azuremanaged`). This breaks the resolver for every
# agent in this repo.
#
# The Dockerfile installs `agent-framework` with --no-deps to skip the
# broken transitive, then installs the needed transitive deps below
# (specifically `agent-framework-core` *without* the `[all]` extra).
#
# Remove --no-deps once upstream fixes agent-framework-durabletask.
